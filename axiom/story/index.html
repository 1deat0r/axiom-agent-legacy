the problem

Autonomous agents spend like no one's watching.

Give an agent a goal and it will call the model until the job is done — or until the bill lands. You find out the cost after the run, not before. Axiom refuses to spend what you haven't approved.

the spine

Every call priced. Every run capped.

This is the whole point. Two halves of one promise: you can see what it costs, and you can stop it before it costs too much.

Cost-visible

Every model call is priced from a per-model table — input, output, cache reads, cache writes, reasoning tokens. When a provider doesn't report usage, Axiom says unknown. It never invents a number to look busy.

Spend-capped

A hard ceiling in dollars. The loop checks the ledger before every call and stops the moment it would cross the line. Sub-agents inherit the cap. A cap of 0 means zero calls — for when you want to watch it plan and refuse.

sovereignty

Your agent is a file you own.

Memory and skills don't live in a vendor's black box — they live in byte-compatible JSON you control. Run on the provider you choose, switch when you want, and walk away with your data intact.

Store-first memory

Everything Axiom learns is written to a JSON store you can read, back up, and diff. The profile is a derived view — the store is the truth.

No lock-in

Multi-provider by design. Text runs on DeepSeek; local vision runs on an Ollama model in your own machine. Your agent, your compute, your call.
