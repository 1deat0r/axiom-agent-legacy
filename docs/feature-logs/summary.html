Goal & assumptions

A gateway-local /search <query> command that answers "what did we decide about X in a past session?" by full-text (FTS5) searching the agent's session archive — scoped to the anchored project by default, crossing projects only via an explicit guarded --all, every hit labeled by its project. Plus discovery/browse and scroll. Assumption: "session DB" = the repo's real JSONL session archive; FTS5 via node:sqlite (no new dependency); a session belongs to a project iff its header cwd is under that project's root.

Key decisions

  • Persistent SQLite session-DB index (entries + sessions, FTS5 external-content + triggers, reconciled by size+mtime keyed by file path) — no per-call rebuild, matching the card.
  • Project isolation: default projectRoot-scoped; --all is the only cross-project path, labeled by project.
  • Trigram tokenizer; 3-char minimum; stable ORDER BY score, rowid for scroll paging.
  • /sessions = discovery/browse (newest-first, project-labeled), same scoping rules.
