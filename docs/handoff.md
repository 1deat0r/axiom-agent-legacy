# Axiom — handoff: the pi baseline shift (ADR-0013)

**Date:** 2026-08-11 · **Session:** owner-directed major shift — "Pi Agent
latest version becomes the baseline for axiom-agent; then we begin adding
capabilities pi did not have."

## What happened

### 1. Verified the baseline facts (unit research, no code touched yet)

- pi = `github.com/earendil-works/pi`, MIT, npm-workspaces monorepo
  (packages: tui, ai, agent, coding-agent, client, protocol, server,
  session-backends, telemetry, evals). Default branch `main`.
- Latest release **v0.84.1** (2026-08-07); `main` 89 commits ahead of the tag.
- npm packages all 0.84.1 / MIT: pi-tui, pi-ai, pi-agent-core,
  pi-coding-agent (`bin: pi`), pi-client, pi-protocol, pi-telemetry,
  pi-storage-sqlite-node.
- ~1,100 TS files / ~115k lines. pi HAS cost display + usage totals,
  reasoning/thinking levels, compaction, sessions/skills/memory, provider
  config + custom-provider extension point. pi does NOT have: a hard spend
  cap, the per-session/lifetime cost ledger, a provider catalog + wizard, a
  messaging gateway (Telegram), memory eviction.

## Commit story (honest note)

The ritual layer (ADR-0013, SOUL/CONTEXT/AGENTS, ADRs 0001-0012, ports.md,
handoff) and the three test-pin fixes landed in one commit (bc3f2106) because
pi's husky pre-commit gate (`npm run check`, incl. tsgo) blocks until the
whole tree type-checks, and the tag's stale pins were exactly what failed it.
The ADR itself documents the shift; the commit message tells the fix story.
Accepted as-is on the fresh branch; a rewrite would need a force-push for no
functional gain.
