Skills that learn procedural memory — steps 1–4: capture + security audit + auto-flag + unattended hook

Timestamp: 2026-08-12  ·  Model: Axiom coding-agent (feat/skill-capture worktree)  ·  ADR-0020

Goal & assumptions

When a completed task is flagged as reusable, generate a validated, provenance-bearing markdown skill that bundles the task prompt + its ordered steps, persist it to a skills directory, verify it loads via the real skill loader, and offer the result — as a core skill-capture module plus a standalone axiom skill-capture CLI, all unit-tested.

Assumptions (reviewed): step 1 takes an explicit flag (CLI args / JSON capture); step 2 is the AST-level security audit of third-party skills; step 3 is automatic flagging (a completed task is scored and only captured when reusable). Hub/sync over agentskills.io remains. The audit is conservative and targets third-party skills; bundled first-party skills are operator allowlisted.

Plan as executed

  • Step 1 (capture): types + document.ts + capture.ts (no-overwrite, real-loader verify) + CLI + main wiring → vitest
  • Step 2 (audit): python-ast.ts + rules.ts + audit.ts + CLI + main wiring → vitest
  • Docs: ADR-0020/0021, CONTEXT terms, named handoff → full test.sh

Key decisions

  • Reuse loader validators. Exported validateName/validateDescription/MAX_NAME_LENGTH from skills.ts (single source of truth) so a generated document can never be silently dropped.
  • Provenance always emitted into metadata.provenance (source, createdAt, optional sessionId/trigger).
  • No-overwrite persist — a capture must never clobber a hand-written skill.
  • Verification via the real loader (loadSkillsFromDir) asserting zero diagnostics — the non-tautological proof of validity.
  • CLI seam mirrors the gateway command pattern; minimal blast radius (3 exports / 5 lines touched in shared files).

Step 4 — unattended runtime hook (ADR-0023)

  • Builtin agent_end extension: buildTaskTraceFromMessages (prompt + tool-call steps + completion) → evaluateTaskForCapture → materialize + verify + offer, no caller.
  • Writes to <AXIOM_HOME>/captured-skills; inert unless AXIOM_SKILL_CAPTURE_AUTO=1; never blocks.
  • test/extensions/skill-capture.test.ts (5 tests).

Step 3 — automatic flagging (ADR-0022)

  • evaluateTaskForCapture(trace) — deterministic, tunable heuristic (complexity + reusable/one-off signals + completion), exported weights/signals/threshold.
  • axiom skill-capture-auto <trace.json> [--out] [--force] [--json] — reuses the capture+verify pipeline; provenance source: "auto".
  • Flagged → capture; un-flagged → reasons + suggest --force; incomplete/thin tasks not captured.

Step 2 — security audit (ADR-0021)

  • Real Python AST via subprocess python3 + ast walk; graceful structural fallback with a note when python is absent.
  • Structural scanners for JS, shell, and markdown code fences (pipe-to-shell, destructive, reverse-shell, privilege, eval).
  • Conservative verdict: any block → BLOCK, else any warn → WARN, else ALLOW (“skills_guard”).
  • CLI axiom skill-audit <dir> [--json] + renderSkillAudit.
