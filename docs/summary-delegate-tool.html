Axiom — Delegate tool (feature #5: Delegate + script-as-tool RPC)

Generated 2026-08-12 · model: Axiom coding agent (feature loop v2) · reviewers: RLM subagents (delegate-plan-reviewer, delegate-impl-reviewer[2]) · branch feat/delegate-rpc

Goal & assumptions

A delegate tool that spawns an isolated helper process (existing --mode rpc / RpcClient bridge), runs one bounded task inside it, and returns to the parent session only a compact result block {ok, summary, tokens, cost, helper?, error?} — a multi-step pipeline collapses into one zero-context-cost turn; the helper's intermediate calls never enter the parent context. Assumption: “helper process” = the existing RPC bridge (least new surface, literal process spawn), not the async RLM message model (kept for fire-and-forget).

Plan as executed

  • extensions/delegate/types.ts — compact block + params types.
  • extensions/delegate/result.ts — pure capSummary/toDelegateResult (no-transcript guarantee).
  • extensions/delegate/bridge.ts — narrow injected RpcDelegateBridge + createRpcClientBridge over RpcClient; parseModelRef.
  • extensions/delegate/index.ts — delegate tool (injectable bridge, timeout clamp, finally-stop).
  • extensions/index.ts — registered in builtInExtensions.
  • test/extensions/delegate.test.ts — 22 neutral (stub bridge) + 1 live-gated.
  • Docs — ADR-0029, handoff, running log, this page.

Key decisions

  • Reuse the existing RpcClient/--mode rpc process bridge rather than extending the async RLM message model.
  • Per-call fresh helper process: start → runTask → stop() in finally (no cross-call state, no orphan on error/timeout).
  • Compact block reports only recorded tokens/cost from SessionStats (never guessed — ADR-0010 ethos).
  • Injected bridge keeps neutral tests deterministic (no process, no keys); genuine process path is live-gated.
  • Honor the requested model param via parseModelRef (not merely echoed).
