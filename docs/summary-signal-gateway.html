Signal gateway · project-manager assistant

feature summary · 2026-08-12 (UTC) · Claude Fable 5 (top-level coding agent), Feature Implementation Loop v2

Goal & assumptions

Axiom's first living surface on the prime-agent v0.7.2 baseline: the agent, riding a profile's SOUL.md, is reachable over Signal (signal-cli); the user messages it and it replies as a project manager (gateway-local commands manage profiles/SOUL.md and per-profile projects). One sender = one session.

Success criterion: axiom gateway --transport signal --profile <name> boots the profile identity, maps each sender to a session, routes to agent replies or gateway commands, sends raw-text replies over signal-cli — tests + npm run check+tsgo green; live signal-cli link operator-blocked.

  • Fresh port of ADR-0001/0004/0006 (gateway, never built before) — a surface, not an extension.
  • Signal transport shells to signal-cli; live link operator-blocked; tests use a fake stub.
  • Per-message run reuses the headless print-mode seam (axiom -p … --profile --session-id).
  • Commands gateway-local (/help /profiles /projects /soul); projects = minimal per-profile registry; root guard deferred.
  • Signal streaming (ADR-0004) is a follow-up; this loop ships batch-send raw text.

Key decisions

  • Gateway = surface, not extension: per-message runs shell the real CLI (axiom -p) behind a CompletionRunner, so all of main()'s setup (models, providers, axiom extensions, profile env) is reused, not duplicated.
  • One sender = one session: deterministic gw-<hash> session id re-passed via --session-id; JSON channel index (ADR-0006) persists the mapping.
  • SOUL.md rides: --profile points the run at the profile home; the ported axiom-profile extension appends SOUL.md on before_agent_start.
  • Commands never reach the model: /help, /profiles, /projects, /soul; unknown -> usage hint.
  • Owner gate = sender allowlist (<AXIOM_HOME>/gateway/config.json); unknown senders denied before the model.
  • Per-channel serialization + batch raw-text reply (ADR-0001); streaming is a follow-up.
