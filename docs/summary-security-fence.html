Key decisions

  • Two pure gates on one seam, mirroring the workspace guard: URL egress safety + an opt-in approved-tool ladder (Hermes approval.py lite).
  • Opt-in sensitive set (default empty) — never pretend a string fence confines freeform bash/ipython.
  • Honest DNS boundary: literal private/loopback IPs (v4+v6 incl. ::ffff: mapped) and loopback-patterned names blocked; arbitrary named hosts allowed + recorded follow-up.
  • Reasons name the unsafe property (scheme/host/credentials) so a model can self-correct.
  • Escape hatches: AXIOM_FENCE_ALLOW (approved tools), AXIOM_FENCE_ALLOW_HOSTS (allowed URL hosts).
  • Approval prompt, path security, threat patterns, skill provenance gate, tool-output limits = later steps, recorded not faked.
